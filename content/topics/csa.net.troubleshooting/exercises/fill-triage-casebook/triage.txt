# The triage desk's sheet: one block per case in /srv/cases. For each case:
#   failed   = F/N: of the N loads in the case's monitor.log, the F that
#              failed, such as 3/40. A load failed when its exit status
#              isn't 0 or its HTTP status is 400 or more; a slow load that
#              worked hasn't failed
#   layer    = the layer whose mechanism fails: link (ARP, MAC addresses),
#              network (IP, routes, ICMP, MTU), transport (TCP, UDP, ports,
#              NAT's port table), application (HTTP, servers, load balancers),
#              naming (DNS) or security (TLS, IPsec's keys and proposals)
#   where    = the machine where the cause is, as the ticket names it
#   cause    = one of the causes in /srv/cases/causes.txt, as it is written there
#   evidence = FILE:LINE, the one line in the case's folder that shows the
#              cause, such as session.txt:14 (grep -n prints line numbers)
# Cases 1 and 2 are filled in as examples.
