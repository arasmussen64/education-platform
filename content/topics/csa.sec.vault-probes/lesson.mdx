<Intro>

This lab is a probe, not a lesson. It tries the vault lab base, the image the cryptography and secrets labs and Checkpoint 4's third part will start from, so that CI shows what works on its machines before any of those topics is written. One lab uses each of the base's riskiest parts on a real container: OpenBao's first boot and its unsealing after a restart, envelope encryption with OpenBao's transit engine, a database password that OpenBao makes and takes away again, an image built with podman inside the lab, and gitleaks reading a repository's history.

</Intro>

<Recap>

When CI has run it, read the Labs job's log for the probe's timings and checks, write what it showed into the base's README, then remove this topic.

</Recap>
