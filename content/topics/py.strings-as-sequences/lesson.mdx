<Intro>

So far a string has been one thing: a name, a day, a line to print. This topic opens it up. A string is a **sequence** of characters, and Python lets you point at any one of them, cut a piece out, or walk along them with a loop, the same loop you used for `range`.

The reading is the **Text** section of Python's own tutorial. Read it from the start of that section to the end of the part about slicing (stop when it starts talking about `len()`, then read that one short bit too). It uses the interactive prompt, where typing an expression shows its value; in your own programs, you'd `print()` it. Watch for:

- **Indexing:** `word[0]` is the first character, because positions count from **0**. `word[-1]` is the last.
- **Slicing:** `word[2:5]` is the characters at positions 2, 3 and 4. The stop position is left out, exactly like `range`.
- **Strings can't be changed in place.** `word[0] = "J"` is an error; you build a new string instead.
- **`len(word)`**, the number of characters.

Then open the Python Tutor link and press **Next >** to watch `for ch in word` take each character in turn. That part isn't in the reading, and it's the one you'll use most.

<Recap>

```python
word = "python"
#       012345     positions from the front
#      -654321     positions from the back
```

- **One character:** `word[0]` is `"p"`, `word[5]` is `"n"`, `word[-1]` is also `"n"`. The last position is `len(word) - 1`, never `len(word)`: that index is one too far and raises an `IndexError`.
- **A slice:** `word[1:4]` is `"yth"`, positions 1, 2 and 3. Leave a number out to mean "from the start" or "to the end": `word[:3]` is `"pyt"`, `word[3:]` is `"hon"`. A slice that runs past the end just stops at the end, with no error.
- **`len(word)`** is the number of characters, 6 here. An empty string, `""`, has length 0.
- **Looping over the characters:**

```python
count = 0
for ch in word:
    if ch == "o":
        count += 1
```

  Each pass, `ch` is the next character. Any accumulator pattern works here: count characters that match, build a new string with `new = new + ch`, or compare each character with the one before.

- **Strings can't be changed in place.** To change one, build a new string and give it the name: `word = word + "!"`.
- The same square brackets, slices and `len()` will work on lists in Module 5. Learn the habits now and they come for free.

</Recap>
