<Intro>

This time the main resource is reading, not a video: four short sections of the free textbook *Python for Everybody*, from **Operators and operands** down to the end of **Modulus operator**. Stop when you reach "String operations". It takes about 10 minutes. Watch for:

- **The operators**: `+ - * /` as in math, `**` for powers, and a second kind of division, `//`.
- **The order of operations**: which operator Python does first when there are several, and how parentheses change it.
- **`%`**: what's left over after dividing, and why that turns out to be so useful.

Skip the parts about Python 2, which is an old version of Python. Where the book shows `>>>`, that's Python's interactive mode; the **Run** button does the same job here. One detail the book glosses over: `/` always gives a float, so `6 + 4 / 2` prints `8.0`, not `8`.

<Recap>

- **`+ - *`** work as in math. **`**`** is a power: `2 ** 3` is `8`.
- There are **two kinds of division**:
  - `/` is ordinary division, and always gives a **float**: `7 / 2` is `3.5`, and even `6 / 3` is `2.0`;
  - `//` gives the **whole** number of times, rounding down: `7 // 2` is `3`.
- **`%`** gives the **remainder**, what's left over: `7 % 2` is `1`. Together, `//` and `%` split an amount: 135 seconds is `135 // 60` = 2 minutes and `135 % 60` = 15 seconds.
- **Order of operations**: parentheses first, then `**`, then `* / // %`, then `+ -`. Operators on the same level go left to right, except `**`, which goes right to left (`2 ** 3 ** 2` is `2 ** 9`, which is `512`). So `2 + 3 * 4` is `14`, `(2 + 3) * 4` is `20`, and `10 - 4 - 3` is `3`. When in doubt, add parentheses.
- **Types**: two ints give an int, except with `/`. If a float is involved, the result is a float: `3 + 2.0` is `5.0`.
- **Floats are approximate**: `0.1 + 0.2` prints `0.30000000000000004`. That's normal. `round(x, 2)` rounds to 2 decimal places: `round(0.1 + 0.2, 2)` is `0.3`. It doesn't pad with zeros (`round(2.5, 2)` is still `2.5`); to *show* exactly two decimals, the next topic has `:.2f`.
- To **update** a variable, write `count = count + 1`: the right side is worked out first, using the old value. The shortcut is `count += 1`.

</Recap>
