- **`while`**: a condition, a colon, and an indented block that repeats for as long as the condition is `True`. Notice that the condition is checked *before* each repeat.

<Recap>

- **`while condition:`** runs its indented block, then checks the condition again, and keeps going until the condition is `False`. If it's `False` the first time, the block never runs.
- **Three parts of a counting loop:** a start (`i = 0`), a test (`while i < 3:`), and an update inside the block (`i += 1`). Forget the update and the loop never ends.
- **`i += 1`** means `i = i + 1`; `i -= 1` means `i = i - 1`. Python has no `i++`.
- **Counting from 0** with `while i < n:` runs exactly `n` times: 0, 1, 2, … n − 1. Counting from 1 with `while i <= n:` also runs `n` times. Either is fine; mixing them up gives an off-by-one error: a loop that runs once too many or once too few.
- **An infinite loop** is a loop whose condition never becomes `False`. Check two things: does the block change something the condition looks at, and does it change it in the right direction?
- The lines *after* the loop, back at the left margin, run once, when the loop has finished.

</Recap>
