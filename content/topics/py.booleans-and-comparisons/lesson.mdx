<Intro>

So far every program you've written does the same thing every time. This clip is where programs start to **ask questions**. Watch for:

- **Two equals signs.** `x = 5` gives `x` a value. `x == 5` asks "is `x` equal to 5?" and the answer is `True` or `False`. Mixing them up is the most common mistake in this module.
- **The six comparison operators**: `==`, `!=`, `<`, `>`, `<=` and `>=`. Each gives a `True` or `False` answer, which David calls a *Boolean expression*.
- **The first `if` statements.** David uses them to print something only when a comparison is `True`. Notice the colon at the end of the line and the indented line under it. The next topic is all about `if`; here, concentrate on the questions being asked.

The clip stops just as David is about to introduce `elif`, which is where the next topic picks up.

</Intro>

<Recap>

- A **comparison** asks a question about two values and answers `True` or `False`: `3 < 5` is `True`, `3 == 5` is `False`.
- The six operators: `==` equal, `!=` not equal, `<` less than, `>` greater than, `<=` less than or equal, `>=` greater than or equal.
- `True` and `False` are values with a type of their own, **`bool`**. `type(3 < 5)` is `<class 'bool'>`, and you can print a comparison's answer directly: `print(3 < 5)` prints `True`.
- **`=` is not a question.** `age = 18` makes `age` refer to 18. To ask whether `age` is 18, write `age == 18`. Inside a `print(...)`, `age = 18` means something else entirely (a keyword argument) and gives a `TypeError`.
- **Text and a number are never equal.** `input()` gives text, so if someone types `7`, then `answer == 7` is `False`: `"7"` is text and `7` is a number. Convert first, with `int(input(...))`, if you want to compare numbers.
- Numbers compare as numbers whatever their type: `5 == 5.0` is `True`.

</Recap>
