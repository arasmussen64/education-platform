<Intro>

This lab is a probe, not a lesson. It tries the identity-lab base, the image every Module 4 identity lab will start from, so that CI shows what works on its machines before any Module 4 topic is written: an identity provider (Keycloak) booting on a machine of the lab's network, a site that signs people in through it, an API that checks its tokens, and a server whose clock is wrong until its time sync is mended. It has the shape of Checkpoint 4's second part, and is not that lab.

</Intro>

<Recap>

When CI has run it, read the Labs job's log for its boot time and contract time, put its seconds in `tools/lab-seconds.json`, then remove this topic once Module 4's own identity labs exist.

</Recap>
