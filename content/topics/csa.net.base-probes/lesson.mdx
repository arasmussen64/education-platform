<Intro>

These two labs are probes, not a lesson. They try the network-lab base, the image every Module 3 lab will start from, so that CI shows what works on its machines before any Module 3 topic is written. The first builds a route-based IPsec tunnel (a VTI) with BGP over it; the second runs a small internet of name servers, a load balancer, web servers, a NAT router and a slow link.

</Intro>
