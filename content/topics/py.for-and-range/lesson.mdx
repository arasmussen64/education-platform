<Intro>

A `while` loop needs three parts you write yourself: a start, a test and an update. When you just want to repeat something a known number of times, Python has a shorter way. Watch for:

- **`for` over a list.** David first loops over `[0, 1, 2]`: the loop variable takes each value in turn, and the block runs once per value. Lists get their own module later; here they're just a way to say "these values".
- **`range(3)`**, which produces `0, 1, 2` for you: three values, starting at 0 and stopping *before* 3. This is the same counting-from-0 habit as the last topic, and it's the single most common source of off-by-one errors, so look closely at where it stops.
- **The underscore.** When the loop variable isn't used inside the block, programmers name it `_`, a signal that says "I'm only counting".
- **A loop with no loop.** `print("meow\n" * 3)` repeats text instead, a reminder that a loop isn't always the only tool.

<Recap>

- **`for i in range(n):`** runs its block `n` times, with `i` taking the values `0, 1, …, n − 1`. Nothing to start, test or update by hand.
- **`range(start, stop)`** counts from `start` and stops *before* `stop`: `range(1, 6)` is 1, 2, 3, 4, 5. **`range(start, stop, step)`** jumps by `step`: `range(0, 10, 2)` is 0, 2, 4, 6, 8, and a negative step counts down: `range(5, 0, -1)` is 5, 4, 3, 2, 1.
- **The stop value is never included.** To get 1 to 10, write `range(1, 11)`. Check the first and last values of a range before trusting a loop.
- **`_`** as the loop variable means "I don't use this value": `for _ in range(3): print("meow")`.
- **`for` or `while`?** Use `for` when you know how many times (or what values) before the loop starts. Use `while` when the loop has to keep going until something changes, like the user typing a valid answer.
- After the loop, the loop variable keeps its last value, which is rarely what you want to print. Use the number you looped to instead.

</Recap>
