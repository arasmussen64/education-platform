<Intro>

Module 1 counted chances with dice and a table of 1,000 people. This module is the probability and statistics that make a model's numbers mean something, and it starts with the objects everything else is built from: a **random variable**, a number that chance decides, and its **distribution**, the list of values it can take and how likely each is. Four distributions cover most of what a model meets, and every one of them can be **simulated** (the computer draws made-up values that behave the way the distribution says) in a line of NumPy, which is how this topic checks every claim it makes.

The main resource is **OpenStax _Introductory Statistics 2e_**: chapter 4 on discrete random variables (sections 4.1 to 4.3, the binomial above all), section 5.2 on the uniform distribution, and chapter 6 on the normal (sections 6.1 and 6.2); about 40 minutes, skimming the worked examples. StatQuest's short video on probability distributions is the picture version. Watch for:

- **A table for counts, a curve for measurements:** probability mass for discrete, probability density for continuous.
- **The binomial's formula** counts the ways and multiplies the chances.
- **The 68-95-99.7 rule** for the normal: how much sits within one, two and three standard deviations.

<Recap>

- **A random variable** is a number whose value chance decides: a flip (0 or 1), a count of heads, a height. **Discrete** ones take separate values (counts); **continuous** ones take any value in a range (measurements). Its **distribution** says which values are possible and how likely each is.
- **A seeded generator.** `rng = np.random.default_rng(1)` makes a random-number generator that starts from the **seed** 1, so every run produces the same draws: a simulation you can check, and a bug you can repeat. Change the seed for a fresh **sample** (a set of draws; this topic uses 100,000 at a time). Pyodide and CPython give the same draws for the same seed.
- **Bernoulli(p):** one yes-or-no with chance `p` of yes. Simulate it with `rng.random(size) < p`, which is `True` with chance `p`. One email being spam; one patient testing positive.
- **Binomial(n, p):** the number of yeses in `n` independent tries, each with chance `p`. `rng.binomial(n, p, size)`. Its **probability mass function** (PMF), the table of chances for each count `k`, is `math.comb(n, k) * p**k * (1 - p)**(n - k)`: the number of ways to pick which tries are yeses, times the chance of one such pattern. For `n = 10, p = 0.3`: 0.028 for no heads, 0.121 for one, 0.233 for two, 0.267 for three (the most likely), and the whole table sums to 1.
- **Checking a simulation against the table:** `np.bincount(sample, minlength=n + 1) / len(sample)` is the fraction of draws at each value, the **empirical** PMF. With 100,000 draws it matches the formula to within a few thousandths (0.235 against 0.233 for two heads). A **histogram** is the same idea for measurements: `np.histogram(sample, bins)` counts how many fall in each **bin** (interval), and a row of `#` per bin draws it as text.
- **Uniform(a, b):** any value between `a` and `b` equally likely; `rng.uniform(a, b, size)`. The chance of being below 0.25 on `[0, 1]` is 0.25; the chance of being **exactly** 0.25 is 0.
- **Density, not mass.** A continuous variable has infinitely many values, so a single one has probability zero. Its distribution is a **density** curve, and probability is the **area** under it between two values: all questions about a continuous variable are about ranges. The density's height is not a probability (it can be above 1).
- **Normal(μ, σ):** the bell curve with mean `μ` and standard deviation `σ`, the shape sums of many small independent effects make: heights, measurement errors, a model's errors. `rng.normal(mu, sigma, size)`. The **68-95-99.7 rule:** about 68 percent of draws lie within one `σ` of the mean, 95 within two, 99.7 within three (0.684, 0.955 and 0.997 in the worked example's 100,000 draws).
- **In machine learning:** a **classifier** (a model that predicts which class an example belongs to) outputs the `p` of a Bernoulli; a count of errors in a test set is binomial; the normal is what least squares assumes about the errors (next topics make that exact), and the uniform is where random starting weights come from.

</Recap>
