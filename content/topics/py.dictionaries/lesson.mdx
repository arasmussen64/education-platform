<Intro>

A list finds things by *position*: the third student. A **dictionary** finds things by *name*: Hermione's house. Whenever your data is pairs, a name and the thing that goes with it, a dictionary is the shape. In this clip David has a list of students and wants each one's house. Watch for:

- **Two lists in parallel** first (`students` and `houses`), and why that's fragile: nothing ties position 2 in one to position 2 in the other.
- **Curly braces** make a dictionary: `{"Hermione": "Gryffindor", ...}`. Each entry is a **key**, a colon, and a **value**. David notes the braces have nothing to do with f-strings; Python just reuses the character.
- **Looking up by key:** `students["Hermione"]` gives her house. A word as an index, instead of a number.
- **Looping over a dictionary gives its keys.** `for student in students:` visits the names; `students[student]` then gets each house.

<Recap>

```python
phone = {"Ada": "555-1234", "Bob": "555-9876"}   # keys -> values
phone["Ada"]                  # "555-1234": look up by key
phone["Cy"] = "555-0000"      # add an entry
phone["Bob"] = "555-1111"     # change one
del phone["Ada"]              # remove one
"Cy" in phone                 # True: is this a key?
len(phone)                    # how many entries

for name in phone:                    # the keys
    print(name, phone[name])
for name, number in phone.items():    # keys and values together
    print(f"{name}: {number}")
```

- **Keys are unique;** assigning to an existing key replaces its value. Keys are usually strings or numbers; values can be anything, including lists.
- **A missing key is a `KeyError`** when you read it: `phone["Zed"]`. Check with `in` first, or use `phone.get("Zed", "unknown")`, which gives the default instead of an error.
- **Looping gives keys.** `phone.values()` gives just the values, `phone.items()` gives pairs. Entries keep the order they were added in, which is also the order they print in.
- **Counting**, the dictionary's most common job:

```python
counts = {}
for ch in word:
    if ch in counts:
        counts[ch] += 1       # seen before: add one
    else:
        counts[ch] = 1        # first time: start at one
```

  Or in one line: `counts[ch] = counts.get(ch, 0) + 1`.

- **Dictionaries are changed in place**, like lists: two names for one dictionary see each other's changes, and a function given a dictionary can change the caller's. `dict(d)` makes a copy.

</Recap>
