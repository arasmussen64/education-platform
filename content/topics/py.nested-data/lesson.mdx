<Intro>

A list can hold anything, including other lists and dictionaries. That one fact gives you the two shapes most real data comes in: a **grid** (a list of lists: rows, each a list of cells) and a set of **records** (a list of dictionaries: things, each with named fields). A spreadsheet is both at once. In this clip David gives each Hogwarts student a name, a house and a patronus, and ends up with a list of dictionaries. Watch for:

- **One dictionary per student**, and then **a list of them**. Each student's facts travel together.
- **Reading a field:** `student["name"]` inside a loop over the list. Outside in: the loop picks a dictionary, the key picks a field.

Grids aren't in the clip, so they're in the recap and the example below. Then open the Python Tutor link and press **Next >**: it draws a grid as boxes inside a box, and records as dictionaries inside a list.

<Recap>

**A grid: a list of lists.**

```python
grid = [
    [1, 2, 3],      # row 0
    [4, 5, 6],      # row 1
]
grid[1][0]          # 4: row 1, then column 0, outside in
len(grid)           # 2 rows
len(grid[0])        # 3 columns

for row in grid:            # each row is a list
    for cell in row:        # each cell is a value
        print(cell, end=" ")
    print()
```

Build a grid by appending rows: start with `[]`, make each row a list, `append` it. To get a column, loop over the rows and take `row[index]` from each.

**Records: a list of dictionaries.**

```python
students = [
    {"name": "Ada", "score": 91},
    {"name": "Bob", "score": 78},
]
students[1]["score"]        # 78: the second record, then its field

for student in students:
    print(student["name"], student["score"])
```

Everything from the list topics works on a list of records: filter with a loop and `append` (the students who passed), transform (just the names), search (the first record whose name matches), and best-so-far (the highest score) by comparing a field.

**Choosing a shape.** Same kind of value, reached by position: a list of lists. Things with named parts: a list of dictionaries. A dictionary whose values are lists (`{"Ada": [91, 85], ...}`) fits "one list per name". There's rarely one right answer; pick the shape that makes the loops you need simplest to write.

**Nested data and copies.** Copying the outer list (`list(grid)`) gives a new outer list that still holds the *same* inner lists. To copy a grid fully, copy each row too: loop over the rows and append `list(row)`.
