<Intro>

Most of what programs do with lists comes down to a handful of moves: keep some items, change every item, find one, put them in order, take a piece. This topic gives each move a name and a shape you can write from memory. There's no video; the reading is two short sections of the Python tutorial.

Read **More on Lists** first, which lists what a list can do (`append`, `insert`, `remove`, `pop`, `index`, `count`, `sort`, `reverse`, `copy`). You don't need to memorize them all; notice which ones *change the list* and which *give something back*. Skip the parts about stacks, queues and list comprehensions for now; comprehensions are a shortcut you'll meet later. Then read the second paragraph of **Looping Techniques**, about `enumerate`, which gives you the position and the item together. (Its first paragraph uses a dictionary, which comes later in this module; skip it for now.)

Then work through the example below. The two loops at its heart, the **filter** and the **transform**, are the patterns this topic is about.

<Recap>

**Filter and transform:** make a new list from an old one.

```python
passing = []                    # filter: keep the items that pass a test
for score in scores:
    if score >= 60:
        passing.append(score)

doubled = []                    # transform: change each item
for score in scores:
    doubled.append(score * 2)
```

Start with an empty list, loop over the old one, `append` to the new one. The old list is untouched, which is usually what you want.

**Search:**

- `x in items` is `True` when `x` is one of the items.
- The position of the first match: loop over `range(len(items))`, and `return i` as soon as `items[i]` matches; after the loop, return `-1` for "not found". (`items.index(x)` does this too, but raises an error when `x` isn't there.)

**Sort and slice:**

- `sorted(items)` gives a **new** sorted list; `sorted(items, reverse=True)` puts the biggest first. The original is unchanged.
- `items.sort()` sorts the list **in place** and returns `None`. Never write `items = items.sort()`.
- Slices work as on strings: `items[:3]` is the first three, `items[-3:]` the last three, `items[1:4]` positions 1 to 3.
- `min(items)`, `max(items)` and `sum(items)` do what they say for lists of numbers; `len(items)` counts.

**Which to reach for:** a new list when the old one is still needed (filter, transform, `sorted`); in-place changes (`append`, `sort`) only when nothing else is using the list.

</Recap>
