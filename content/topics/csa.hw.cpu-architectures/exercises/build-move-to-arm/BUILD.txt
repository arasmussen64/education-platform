How the shop's programs are built (notes from the build team)

The release for our x86-64 servers is built on the build machine with:

    gcc -O2 -march=x86-64-v3 -o bin/shop-api src/shop-api.c
    gcc -O2 -march=x86-64-v3 -o bin/shop-thumb src/shop-thumb.c

-march=x86-64-v3 lets the compiler use AVX2, which every one of our x86
servers has.

Arm: not done yet. Someone suggested -march=armv8.2-a+sve for the Arm
servers, since shop-thumb's brighten loop goes faster with SVE.
