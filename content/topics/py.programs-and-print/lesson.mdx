<Intro>

Your first program is one line long. In this part of Harvard's CS50 Python course, watch for:

- **`print`**: what it does with the text between its parentheses, and why that text is in quotes.
- **How a program runs**: Python reads your code from the top, one line at a time.
- **The first bug**: what happens when a single `)` is missing, and how the error message points to the problem.

David writes his code in VS Code and runs it from a terminal by typing `python hello.py`. You don't need either: the editor on this page and its **Run** button do the same job.

<Recap>

- A **program** is a list of instructions. Python runs them in order, from the top, one line at a time.
- **`print`** shows what's inside its parentheses. Text goes in quotes: the quotes mark where the text starts and ends, and they aren't shown.
- `print()` with nothing inside prints a **blank line**. Separate several pieces of text with **commas**, and they're printed on one line with a space between each.
- Python takes you **literally**. A missing `)` or `"`, or `Print` with a capital P, is enough to stop a program.
- An **error message** says what went wrong on its last line, and where on the line above. Fix one error, run again, and read the next message.
- Two kinds of error so far. With a **syntax error**, Python can't make sense of your code, so nothing runs at all. A **NameError** happens when Python reaches a word it doesn't know, such as text without quotes; the lines before it have already run.

</Recap>
