Constructed, not captured: a teaching example in lab-capture's layout,
not the output of a real machine. Only the files a fleet report reads are
here. Built on 2026-11-11 from the documentation named below.

What an EC2 instance built on the Nitro System presents to Linux: the
Elastic Network Adapter (driver ena) and NVMe disks, both PCI devices that
Nitro cards provide, handed to the instance as SR-IOV virtual functions.
Sources: AWS, "Instances built on the AWS Nitro System",
https://docs.aws.amazon.com/ec2/latest/instancetypes/ec2-nitro-instances.html,
and "The components of the Nitro System",
https://docs.aws.amazon.com/whitepapers/latest/security-design-of-aws-nitro-system/the-components-of-the-nitro-system.html
(both read 2026-11-11); systemd-detect-virt(1), which names a Nitro
instance "amazon".
