What an Azure VM with Accelerated Networking presents to Linux: a
synthetic network interface on VMBus (driver hv_netvsc) that carries the IP
address, and an SR-IOV virtual function of the host's physical card, a PCI
device with the same MAC address (driver mlx5_core on an NVIDIA/Mellanox
host). Disks on VMBus appear as SCSI disks (driver sd). Sources: Microsoft,
"How Accelerated Networking works in Linux and FreeBSD VMs",
https://learn.microsoft.com/en-us/azure/virtual-network/accelerated-networking-how-it-works
(page dated 2026-07-16); systemd-detect-virt(1), which names Hyper-V
"microsoft".

This one was read from inside a container (so systemd-detect-virt alone says
docker) started with the host's network, so it sees the VM's interfaces;
here a rule has renamed the virtual function to enP30832s1.
