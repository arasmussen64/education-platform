<Intro>

You've written every function you've used, apart from the handful built into Python. Real programs lean on **libraries**: code other people wrote, packaged as **modules** you bring in with `import`. Python comes with hundreds. In the first clip David uses two of them. Watch for:

- **`import random`**, then **`random.choice([...])`**: the module's name, a dot, the function. The dot says where the function lives.
- **`from random import choice`**, which lets you write `choice(...)` on its own, and David's reasoning about when that's worth it (less typing) and what it risks (a clash with your own names).
- **`random.randint`** and **`random.shuffle`**, and the habit of **reading the documentation** to find what a module offers.
- **`statistics.mean`**: a second module, same pattern.

<Recap>

```python
import random                      # the module, under its name
import statistics
from math import sqrt              # one name, brought in directly

random.choice(["heads", "tails"])  # module.function
random.randint(1, 6)               # a whole number from 1 to 6, inclusive
random.shuffle(cards)              # changes the list in place, returns None
statistics.mean([2, 4, 9])         # 5
sqrt(16)                           # 4.0, no module name needed
```

- **A module is a file of Python code.** `import random` runs that file once and gives you its functions under the name `random`. The **standard library** is the set of modules that comes with Python; the docs at docs.python.org list each one's functions.
- **Two forms:** `import m` then `m.f()` keeps names tidy and shows where `f` came from. `from m import f` lets you write `f()`, at the risk of clashing with your own `f`. Either is fine; be consistent within a file.
- **Read the signature.** `random.randint(a, b)` includes both ends; `random.shuffle` returns `None` and changes the list, so `cards = random.shuffle(cards)` loses the deck (the lesson of Module 5). When in doubt, the docs say.
- **A few you'll use:** `random` (choice, randint, shuffle), `statistics` (mean, median), `math` (sqrt, pi, floor), `csv` (last topic). Later modules bring `json`, `datetime`, `pathlib`.
- **Your file is a module too.** Another file can `import yours` and call its functions, which runs your file top to bottom first. That's why the program's steps live in `main()` and the last lines are `if __name__ == "__main__": main()`: `__name__` is `"__main__"` only when the file is run directly, so importing gives the functions without running the program.
- **Other people's packages** (`pip install ...`) work the same way once installed; they aren't available in this page's sandbox.

</Recap>
