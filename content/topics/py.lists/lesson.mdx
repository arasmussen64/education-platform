<Intro>

So far every variable has held one value. A **list** holds many, in order: the students in a class, the prices on a receipt, the scores in a game. Module 3 already touched lists ("these values" in a `for` loop); this module makes them the main event. In this clip David keeps a list of students and works out how to get at them. Watch for:

- **Making a list**: square brackets with the values inside, separated by commas. A list of three strings is still one value, held by one name.
- **Indexing**: `students[0]` is the first item, because positions count from **0**, exactly as in a string. `students[2]` is the third.
- **Looping over the items**: `for student in students:` visits each item in turn, however many there are.
- **`len`** and **`range(len(students))`**: when you need the *positions* (0, 1, 2) rather than the items, loop over a range as long as the list and index with it.

The clip stops where David moves on to dictionaries, which is two topics from now. Then read the tutorial's **Lists** section, which adds what the clip leaves out: changing an item, `append`, and slices, which work on lists just as they did on strings.

<Recap>

```python
shopping = ["milk", "bread", "eggs"]   # make a list
shopping[0]                            # "milk": positions count from 0
shopping[-1]                           # "eggs": -1 is the last item
len(shopping)                          # 3

shopping[1] = "rolls"                  # replace an item
shopping.append("tea")                 # add to the end
del shopping[0]                        # remove the item at a position
"tea" in shopping                      # True: is it one of the items?

for item in shopping:                  # the items, one at a time
    print(item)
for i in range(len(shopping)):         # the positions, when they matter
    print(i, shopping[i])
```

- **A list is one value that holds many,** in order. Items can be any type, and a list can be empty: `[]`.
- **Indexing and slicing are the same as for strings:** from 0, `-1` for the last, `shopping[1:3]` for a piece. The last position is `len(shopping) - 1`; `shopping[len(shopping)]` is an `IndexError`.
- **Lists can be changed; strings can't.** `shopping[1] = "rolls"` works; `word[1] = "x"` doesn't. `append` adds to the end and returns `None`, so never write `shopping = shopping.append(...)`.
- **Items or positions.** `for item in shopping` when you only need each value; `for i in range(len(shopping))` when you need where it is, or need to change items as you go.
- **`in`** asks whether something is one of the items. **`len`**, **`min`**, **`max`** and **`sum`** work on lists of numbers too.
- **A string's `split()`** gives a list of its words: `"the quick fox".split()` is `["the", "quick", "fox"]`. Checkpoint 3's word counting is one line now.
- Printing a list shows it with brackets and quotes, `['milk', 'rolls']`; that's how Python writes a list, not something to format away.

</Recap>
