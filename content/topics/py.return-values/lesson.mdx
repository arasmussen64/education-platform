<Intro>

The functions you wrote in the last topic *did* things: they printed. The most useful functions *work something out and hand it back*, the way `input()` hands back what was typed and `int()` hands back a number. That handing back is `return`. In this short clip David writes `square`, a function that returns `n * n`, and uses it inside `print`. Watch for:

- **The built-in functions you already use return values.** `input()`, `int()`, `float()`: each gives something back that you store or pass on.
- **`return n * n`**: the keyword `return`, then the value to hand back. The call `square(x)` *becomes* that value, so it can sit inside another call, like `print("x squared is", square(x))`.
- What David *doesn't* do: print inside `square`. The function returns; the caller decides what to do with the result.

Then read the tutorial's **Defining Functions** section, this time for the part about `return`. Notice its remark that a function with no `return` still gives back a value, called `None`, and that `print(fib(0))` shows it.

<Recap>

```python
def square(n):
    return n * n            # hand n * n back to whoever called


result = square(4)          # the call becomes 16; store it
print(square(3))            # or pass it straight into another call
print(square(square(2)))    # or into another square: 16
```

| | `print(value)` | `return value` |
|---|---|---|
| What it does | Shows the value on the screen | Hands the value back to the caller |
| Where the value goes | To the person watching | Into the expression that made the call |
| Ends the function? | No | Yes, at once |
| Can the caller use it? | No | Yes: store it, pass it on, add to it, test it |

- **No `return` means `None`.** A function that only prints (or has no `return` on the path it took) gives back `None`, Python's "nothing" value. If you see `None` printed, a function somewhere returned nothing where you expected a result.
- **`return` ends the function.** Lines after it never run. In a loop, `return` inside the body stops the loop and the function together, which is sometimes exactly right (search until found) and sometimes a bug (returning on the first pass).
- **A function can return a `bool`,** and then it reads like a question: `if is_even(n):`.
- **Return the value, let the caller print.** A function that returns can be used anywhere; one that prints can only print. When in doubt, return.

</Recap>
