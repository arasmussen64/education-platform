<Intro>

Loops become useful when they *collect* something as they go: a running total, a count, the biggest value seen so far. Programmers call these **accumulator patterns**, and they all have the same three-part shape: set a variable up **before** the loop, update it **inside** the loop, use it **after** the loop. You've already written one: the `total += i` in the last topic's practice.

Three to know by name (the recap shows each in code):

- **Running total:** start at 0, add each value.
- **Count:** start at 0, add 1 each time something is true.
- **Best so far:** remember the largest (or smallest) value seen, and replace it whenever a value beats it. The starting value needs care.

The video clip is about a fourth thing loops do: keep going **until something happens**. David wants the user to type a positive number, and won't take no for an answer. Watch for:

- **`while True`**, a loop that's deliberately infinite, so something inside it has to end it.
- **`continue`**, which skips the rest of this pass and goes back to the top of the loop.
- **`break`**, which leaves the loop at once. Notice that the loop ends with `break`, not with the condition.
- How David first writes both `continue` and `break`, then tightens the loop to just `if n > 0: break`.

Then read the short **break and continue Statements** section of the Python tutorial (the second resource). Skip the part about `else` clauses on loops.

<Recap>

**The accumulator shape:** before, inside, after.

```python
total = 0                    # before the loop: the starting value
count = 0
for n in range(1, 11):
    total += n               # inside: update
    if n % 2 == 0:
        count += 1           # a count is a total that goes up by 1
print(total, count)          # after: use it
```

Put the starting line *inside* the loop by mistake and the variable is reset on every pass, so you end up with just the last value.

**Best so far:** compare each value with the best one seen, and replace it if it wins.

```python
largest = 0
for _ in range(3):
    n = int(input("Number? "))
    if n > largest:
        largest = n
```

Starting at 0 works only if every value is bigger than 0. When values might be negative, or you're looking for the **smallest**, start from a value nothing can beat (`smallest = 10 ** 9`), or from the first real value.

**Ending a loop from inside:**

- `break` leaves the loop immediately; the program carries on after the loop.
- `continue` skips the rest of this pass and goes back to the top (to the condition, or the next value).
- `while True:` with a `break` inside is the usual way to repeat something **until the user gives a usable answer**, because the number of tries isn't known in advance:

```python
while True:
    n = int(input("Number? "))
    if n > 0:
        break                # a usable answer: leave the loop
print(n)                     # n keeps its value after the loop
```

Both keywords work in `for` loops too. `break` only leaves the loop it's inside; that matters once loops are nested, two topics from now.

</Recap>
